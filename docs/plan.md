# План общего модуля

## Зачем

«Карман» и «Полка» выросли из одного кода: около 7,2 тыс. строк Rust и 1,7 тыс. строк интерфейса
совпадают буквально, ещё часть — почти. Исправления приходилось делать дважды. Общее выносится
сюда; в приложениях остаются записи, экраны и инструменты для Claude. «Мост» и следующие
приложения начинаются с заготовки на модуле.

## Решения

- Репозиторий — отдельный, открытый, с версиями `vX.Y.Z`. Rust подключается зависимостью по метке,
  интерфейс — пакетом npm из этого же репозитория (его `package.json` будет лежать в корне).
- Основа интерфейса — «Полка». Правила — [design.md](design.md). Экраны «Кармана» переводятся
  на них по разделам, вместе с переносом соответствующей части.
- Форматы данных не меняются. Перед переносом каждой части форматы закрепляются образцами —
  файлами, которые сделала выпущенная версия приложения.
- Приложения различаются настройками. Что приложение обязано задать: название в трёх падежах,
  строки ключей; дальше — порты, метки файлов и пакетов, расширения, имена файлов в облаке,
  версия QR-кода, предел размера вложения.
- «Мост» переписывается на модуле (сейчас он на Go, только для Windows).

## Что учесть на этапах

**1в. Интерфейс.** Совпадают темы, 17 цветовых переменных и экран входа. `Seg` и `Cut` в двух
приложениях имеют разные параметры, из классов стилей общих 57 (в «Кармане» 191, в «Полке» 261).
В модуль идут элементы «Полки»; у «Кармана» своей полосы окна пока нет.

**2. Коннектор.** В «Кармане» те же инструменты вызывает и ИИ внутри приложения — у запуска
инструмента должен остаться признак «кто вызывает»; поэтому инструменты, их настройки и «Вернуть»
остаются в приложениях, а в kit — протокол и связь. Гонка при запуске (приём запросов до открытия
базы) исправлена в обоих приложениях.

**3. Хранилище и обмен.** Таблицы базы в приложениях одинаковые, разное только тело события:
у «Полки» оно универсальное («вид, номер, содержимое»), у «Кармана» — своё у каждого вида записи.
В «Кармане» уже есть функция, которая переводит любое его событие в «вид, номер, содержимое», —
она и станет переходником; журнал «Кармана» не переписывается. Отличия, которые остаются
настройками: порты, метки пакетов (`KRML` / `PLKL`), строки SPAKE2 и MAC, версия QR-кода
(код связи у «Кармана» — в версии 2, у «Полки» — в версии 1), расширения файлов облака.
Передача файлов кусками с докачкой есть только в «Полке» и привязана к книгам — её нужно
обобщить, «Мосту» она нужнее всего.

**Остаётся в «Кармане»:** вход в облако по коду (Яндекс и Google Drive), старый QR-код с ключом
и прежним протоколом обмена, перенос ключа из открытого файла `key.bin`.

## Сделано

- **0.1.0** — `kit-secure`, `kit-core` (PIN-код, название приложения), `kit-tauri` (вход),
  правила дизайна. Проверки: вход и PIN-код — на Linux; на Windows — что ключ, сохранённый
  приложениями до модуля, открывается модулем.
- **0.2.0** — общие сценарии сборки для Windows и Android и общая донастройка Android. Скрипты
  «Полки» и «Кармана» поделены на общую часть и свою; на проектах `tauri android init` обоих
  приложений результат совпал со старыми скриптами файл в файл.
- **0.3.0** — интерфейс: цвета и темы, шрифты, общие стили, элементы экрана, своя полоса окна,
  экран входа (`ui/`, пакет npm). Перенесён из «Полки» без изменений: снимки 44 экранов демо
  «Полки» (телефон и компьютер, светлая и тёмная тема) до и после переноса совпали попиксельно.
- **0.4.0** — протокол коннектора для Claude (`kit_core::mcp`): ответы MCP, доказательство ключа связи,
  файл расширения `.mcpb`. В «Полке» ответы протокола на 16 разных запросов, доказательства ключа и
  описание расширения до и после перехода совпали байт в байт.
- **0.5.0** — стили экрана входа — отдельным самостоятельным файлом `ui/lock.css`, чтобы «Карман» мог
  взять экран входа до перехода на стили kit целиком; `styles.css` подключает его сам. Снимки 60 кадров
  демо «Полки» до и после: 55 совпали попиксельно, в остальных — сглаживание углов клавиш на 2–4 уровня
  из 255 и две точки в кадре с всплывающим сообщением, которые расходятся и между двумя снимками одного кода.
- **0.6.0** — связь коннектора с запущенным приложением (`kit_core::link`): файл связи, приём запросов
  с проверкой ключа, посредник `--mcp`, запуск приложения из посредника на Windows. Перенесена из
  «Полки» и «Кармана», где совпадала построчно; различались только тексты (род названия — теперь
  `AppNames::feminine`). Проверки: посредник в том виде, как он был в «Кармане» до kit, говорит с новым
  приложением, и наоборот; чужая программа на порту не получает ни ключа, ни запроса; приложение не
  выполняет запрос посредника без ключа.
- «Полка»: образцы форматов 0.11.1.
- «Карман»: образцы форматов 0.15.1 (база, резервная копия, папка облака, QR-коды, ключи)
  и проверки, что они читаются.
