# Правила дизайна

Как делать кнопки, отступы, шрифты и экраны в приложениях на общем модуле: «Полка», «Карман», «Мост»
и следующих. Основа — интерфейс «Полки» 0.11.0. С kit 0.3.0 эти стили и элементы лежат в самом kit:
стили — `ui/styles.css`, элементы — `ui/elements.tsx`, экран входа — `ui/lock.tsx` и его стили `ui/lock.css`
(самостоятельные: их можно подключить без остальных стилей kit).

Если правило и код разошлись, чинят код или меняют правило здесь. Оставлять расхождение нельзя:
по этому файлу делаются новые экраны.

## Главное

1. **Спокойный экран.** Один фон, один цвет текста, один акцент. Цветом выделяется только то,
   на что нужно нажать или что нужно заметить.
2. **Цвета — только переменными.** В стилях нет записей вида `#0E5A8A`: только `var(--own)` и другие
   переменные из раздела «Цвета». Так работают все пять цветовых схем и тёмная тема.
3. **Размеры — только из шкал.** Отступ, высота, скругление и размер шрифта берутся из таблиц ниже.
   Нужного значения нет — берётся ближайшее, новое не придумывается.
4. **Палец попадает.** Всё, на что нажимают, не ниже 44 пикселей.
5. **Телефон и компьютер — один экран.** Экран сначала делается для телефона, на ширине от 900
   пикселей меняется только раскладка: меню уходит влево, поля становятся шире.
6. **Готовый элемент, а не новый.** Сначала ищется подходящий элемент из этого файла. Новый вид
   кнопки или поля появляется только вместе с правкой этого файла.

## Цвета

Все цвета — переменные, их значения задаёт цветовая схема (`theme.ts`).

| Переменная | Что это | Где используется |
|---|---|---|
| `--bg` | фон экрана | фон приложения, окон поверх, текст на тёмных кнопках |
| `--surf` | поверхность | поля ввода, нижняя панель, панель «Сохранить» |
| `--inset` | вдавленная поверхность | обычные кнопки, переключатели, выбранный пункт меню, метки |
| `--ink` | основной текст | текст, значки, главная кнопка |
| `--ink2` | второй текст | подписи, пояснения, невыбранные пункты |
| `--ink3` | третий текст | самое тихое: сноски, стрелки разделов |
| `--line` | линии | границы полей, разделители строк |
| `--own` | акцент | ссылки, выбранное, рамка фокуса |
| `--ownBg`, `--onOwn` | фон под акцентом и текст на акценте | выбранная метка-кнопка |
| `--work` | второй акцент | вторая смысловая группа: в «Кармане» — командировки, в «Полке» — кино и сериалы |
| `--workBg`, `--onWork` | фон и текст для второго акцента | кнопка второго акцента |
| `--pos` | хорошо | «готово», «в сети», положительная сумма |
| `--warn`, `--warnBg` | внимание | ошибки, удаление, предупреждения |

Правила:

- Текст на `--bg` и `--surf` — `--ink`, `--ink2` или `--ink3`. На `--own` — только `--onOwn`,
  на `--work` — только `--onWork`.
- Красный (`--warn`) — только для ошибок и необратимых действий. Украшать им нельзя.
- У каждого приложения два акцента: `--own` — основной, `--work` — для второй группы записей.
  Третьего акцента нет.
- Прозрачность вместо цвета не используется, кроме выключенных элементов (см. «Состояния»).

**Схемы.** Пять схем, у каждой светлая и тёмная: Север, Тайга, Байкал, Слива, Графит. Тема:
светлая, тёмная или как в системе. Схему и тему человек выбирает в настройках, выбор хранится
на устройстве. Новая схема — это новый набор тех же переменных, новых переменных она не вводит.

## Шрифты

| Шрифт | Для чего | Начертания |
|---|---|---|
| Golos Text | весь текст | 400 обычный, 500 средний, 600 полужирный |
| Geologica | заголовки и числа (`--num`, класс `.num`) | 300, 400, 500 |

Шрифты лежат в приложении (`@fontsource`), из сети не загружаются. Третий шрифт допустим только
для чтения длинного текста внутри приложения (в читалке «Полки» — Literata).

Размеры текста:

| Размер / строка | Что | Шрифт и начертание |
|---|---|---|
| 40 / 46 | название приложения на экране входа | Geologica 500 |
| 26 / 32 | заголовок экрана (`.screen-title`) | Geologica 500 |
| 20 / 26 | заголовок в верхней строке (`.topbar-title`), код связи | Geologica 500 |
| 17 / 22 | заголовок раздела (`.sec`, `.cut-title`) | Geologica 500 |
| 15 / 21 | основной текст, текст кнопок | Golos Text 400, в кнопках 500 |
| 14 / 20 | малые кнопки, метки-кнопки, сообщения внизу | Golos Text 400–500 |
| 13 / 18 | подписи и пояснения (`.small`), подпись поля | Golos Text 400, подпись 500 |
| 12 / 16 | метки, подписи нижней панели | Golos Text 400 |

Правила:

- Текста мельче 12 нет. Основной текст — всегда 15.
- Жирность: 400 — текст, 500 — кнопки, подписи и заголовки, 600 — выбранный пункт меню и большая
  кнопка. Жирнее 600 интерфейс не пишет.
- Числа, суммы, даты и коды — шрифтом Geologica (класс `.num`); цифры одинаковой ширины включены
  для всего текста, поэтому столбцы чисел стоят ровно.
- Прописными буквами слова не набираются. Исключение — код связи.
- Длинное название в одну строку обрезается многоточием, а не уменьшается.

## Отступы и размеры

**Шкала отступов:** 2, 4, 6, 8, 10, 12, 16, 22 пикселя.

| Отступ | Где |
|---|---|
| 2 | между строками одной надписи (название и подпись под ним) |
| 4 | между подписью поля и полем, между пунктами бокового меню |
| 6–8 | между значком и текстом в кнопке, между кнопками в ряду |
| 8 | между элементами внутри раздела (`.stack-s`) |
| 12 | между частями строки, между блоками окна поверх |
| 16 | поля окна поверх, поля кнопки по бокам |
| 22 | между крупными блоками экрана (`.stack`) |

**Поля экрана:** на телефоне 16 сверху, 20 по бокам, 40 снизу; на компьютере 32 сверху, 40 по бокам,
64 снизу, ширина содержимого не больше 1040. На телефоне учитываются вырез и полоса жестов
(`env(safe-area-inset-…)`).

**Высоты:**

| Высота | Что |
|---|---|
| 40 | малая кнопка, кнопка переключателя |
| 44 | обычная кнопка, кнопка-значок, кнопка-ссылка, пункт меню — наименьшее для нажатия |
| 46 | поле ввода |
| 48 | строка списка, поле поиска |
| 52 | большая кнопка на всю ширину |
| 56 | заголовок раздела настроек, кнопка нижней панели |
| 58 | круглая кнопка «добавить» |
| 60 | клавиша набора PIN-кода |

**Скругления:**

| Радиус | Что |
|---|---|
| 5–6 | метки, значки-наклейки |
| 12 | основное: кнопки, поля, переключатель, пункт меню, сообщение внизу |
| 14 | большая кнопка, поле поиска |
| 16 | клавиши PIN-кода |
| 20 | окно поверх |
| круг | точки, образцы цвета |

Вложенное скругление меньше внешнего на величину поля: кнопка внутри переключателя — 9 (12 − 3).

**Тени** — только у того, что лежит поверх экрана: круглая кнопка «добавить», сообщение внизу, окно
поверх. Карточки и кнопки на экране тени не имеют, их отделяет цвет поверхности или линия.

## Кнопки

| Вид | Класс | Как выглядит | Когда |
|---|---|---|---|
| Обычная | `btn` | фон `--inset`, текст `--ink` | любое действие по умолчанию |
| Главная | `btn primary` | фон `--ink`, текст `--bg` | главное действие экрана или окна |
| С рамкой | `btn line` | рамка `--line`, без фона | второстепенное действие рядом с главным |
| Второго акцента | `btn work` | фон `--work`, текст `--onWork`, высота 48 | главное действие во второй группе |
| Своего цвета | `btn own` | фон `--own`, текст `--onOwn` | главное действие в первой группе, когда рядом есть кнопка второй |
| Опасная | `btn warn` | фон `--warn`, белый текст | необратимое: удалить, стереть |
| Ссылка | `link-btn` | без фона, текст `--own` | действие в тексте, «Забыли PIN?», «Подробнее» |
| Опасная ссылка | `link-btn warn-text` | текст `--warn` | «Отвязать», «Выключить» |
| Значок | `icon-btn` | 44 × 44, без фона | «Назад», «Закрыть», «Ещё» |
| Добавить | `fab` | 58 × 58, фон `--ink`, скругление 17, тень | одно главное действие приложения на телефоне |

Размеры: обычная — высота 44, поля 16 по бокам, скругление 12, текст 15 / 500. Малая (`small`) —
высота 40, поля 12, текст 14. Большая (`big`) — на всю ширину, высота 52, скругление 14, текст 600.

Правила:

- **Главная кнопка на экране одна.** Остальные — обычные, с рамкой или ссылки.
- Текст кнопки — глагол: «Сохранить», «Показать код», «Вернуть». Не «ОК» и не «Да».
- Значок в кнопке стоит слева от текста, между ними 8. Кнопке из одного значка обязательно дают
  подпись для чтения с экрана (`aria-label`).
- Опасная кнопка никогда не главная по расположению: она стоит отдельно или после подтверждения.
- На телефоне главная кнопка формы прилипает к низу экрана панелью «Сохранить» (`save-bar`);
  на компьютере она стоит под формой, шириной не меньше 280.
- Пока действие идёт, кнопка выключена (`disabled`), а не спрятана.

## Поля и выбор

- **Поле ввода** (`field`): подпись сверху (13, `--ink2`), под ней через 4 — поле высотой 46, рамка
  `--line`, фон `--surf`, скругление 12, поля текста 12. Подсказка внутри поля подпись не заменяет.
- **Поле без подписи** (`input` на самом `input`, `select` или `textarea`): тот же вид, что у поля в `field`.
- **Многострочное поле** (`note` или `textarea.input`): те же рамка и фон, поля 10 и 12, высоту можно тянуть.
- **Поле поиска** (`search-field`): высота 48, скругление 14, рамка 1,5; при вводе рамка `--ink`.
- **Два поля в ряд** (`two`): две равные колонки, между ними 8. На телефоне — не больше двух.
- **Переключатель из нескольких вариантов** (`Seg`): 2–4 коротких варианта на фоне `--inset`,
  выбранный — фон `--ink`, текст `--bg`; если выбор — «личное» или «рабочее», выбранный вариант своего
  цвета (`--own`, `--work`). Для выбора «одно из». Больше четырёх вариантов или длинные названия —
  список, а не переключатель.
- **Метка-кнопка** (`chip`): высота 42, фон `--inset`; выбранная — рамка `--own`, фон `--ownBg`,
  текст `--own` (обёртка может задать свой цвет выбранного: `--accent` и `--tint`). Для выбора
  нескольких из многих.
- **Метка** (`tag`): 12 / 18, фон `--inset`, скругление 5; цветные — `tag work`, `tag own`, `tag warn`,
  `tag pos`. Не нажимается.
- **Галочка**: обычная галочка системы 20 × 20 с текстом справа через 10; нажимается вся строка.

## Строки и разделы

- **Строка** (`row`, элемент `Row`): слева название (`--ink2`), справа значение; высота от 48, сверху
  линия `--line`. Если значение длинное — в столбик (`row block`).
- **Заголовок раздела** (`sec`): 17 / 22, Geologica 500, под ним 8.
- **Раздел под катом** (`Cut`): строка-кнопка высотой 56 с названием (17, Geologica), справа —
  короткое состояние (13, `--ink2`) и стрелка; содержимое раскрывается по нажатию, раскрытые
  разделы запоминаются на устройстве (или их открывает само приложение: `open` и `onToggle`). Так устроены все настройки: один раздел — одна тема
  («Вид», «Вход», «Wi-Fi», «Облако», «Копии», «Claude»).
- **Число с подписью** (`figures`): сверху подпись 13 (`--ink2`), под ней число 24 / 30 шрифтом
  Geologica; на телефоне две колонки, на компьютере четыре.

## Окна поверх и сообщения

- **Окно поверх** (`sheet`): по центру экрана, ширина до 560, скругление 20, поля 16 сверху и 18
  по бокам и снизу, между блоками 12, фон `--bg`, затемнение под ним. Сверху — заголовок (17,
  Geologica) и кнопка-значок «Закрыть», снизу — ряд кнопок, главная первой. Окно закрывается
  кнопкой «Закрыть», клавишей Esc и нажатием мимо окна. Окно в окне не открывается.
- **Сообщение внизу** (`toast`): фон `--ink`, текст `--bg`, 14 / 20, скругление 12, ширина до 360;
  исчезает само. Если действие можно отменить, в сообщении есть «Вернуть» — это вместо вопроса
  «Вы уверены?» везде, где отмена возможна.
- **Вопрос перед действием** — только для необратимого (стереть данные, отвязать устройство):
  окно поверх с объяснением, что произойдёт, и опасной кнопкой.
- **Пустой экран** (`empty`): по центру, одна фраза о том, что здесь появится, и одна кнопка, что
  сделать. Без картинок.
- **Ошибка** пишется рядом с местом, где случилась, цветом `--warn`, обычным языком: что не
  получилось и что сделать.

## Раскладка экрана

- **Телефон** (уже 900): содержимое, под ним нижняя панель из 3–5 пунктов (значок и подпись 12,
  высота 56). Над панелью — круглая кнопка «добавить», если у приложения есть одно главное действие.
- **Компьютер** (от 900): слева меню шириной 232 — название приложения, главная кнопка
  («Добавить») и пункты высотой 44 (выбранный — фон `--inset`, текст 600); справа содержимое.
  Круглой кнопки нет.
- **Верх экрана.** У главных экранов — заголовок 26. У вложенных — верхняя строка (`Header`): слева
  «Назад», по центру название 20, справа не больше одного действия.
- **Между блоками экрана** — 22 (`stack`), внутри блока — 8 (`stack-s`).
- **Своя полоса окна** на компьютере: высота 32, цвет как у экрана, без названия и значка; справа
  кнопки «свернуть», «развернуть», «закрыть» шириной 46. За полосу окно перетаскивают. На телефоне
  полосы нет.
- **Настройки** — один экран из разделов под катом; отдельных экранов для каждой настройки нет.

## Экран входа

Название приложения (40 / 46, Geologica 500), подсказка (15), четыре точки PIN-кода (14 пикселей,
между ними 18), клавиатура три в ряд шириной до 300 (клавиши высотой 60, скругление 16, цифры 25
шрифтом Geologica), под ней «Забыли PIN?» ссылкой. На низком экране (до 640 в высоту) клавиши 50,
название 32. Неверный PIN — точки качаются; если в системе выключены анимации, не качаются.

## Значки

- Один набор: контурные, поле 24 × 24, толщина линии 1,75, скруглённые концы.
- Размер 20 — в кнопках, строках и боковом меню; 22 — в нижней панели; 24 — «Назад»; 26 — плюс
  на круглой кнопке; 18 — стрелки разделов и значки в малых кнопках.
- Линия 2 вместо 1,75 — у «Назад», «Закрыть», плюса, стрелок и выбранного пункта нижней панели.
- Цвет значка — цвет текста рядом (`currentColor`).
- Значок без подписи — только для общеизвестного: назад, закрыть, поиск, настройки, добавить.
  У остальных рядом текст.

## Состояния и движение

- **Фокус с клавиатуры:** рамка 2 пикселя цветом `--own` с отступом 2. Убирать её нельзя.
- **Выключено:** прозрачность 0,55, курсор обычный.
- **Выбрано:** в меню и переключателях — фон (`--inset` или `--ink`), а не только цвет текста.
- **Идёт работа:** кнопка выключена, рядом короткий текст («Отправляется…»). Крутящихся значков нет.
- **Движение** короткое: 0,15–0,25 секунды, только для раскрытия разделов и выезда панелей.
  При настройке системы «меньше движения» анимации выключаются.

## Тексты

- По-русски, простыми словами, без технических терминов: «резервная копия», а не «бэкап»;
  «связать устройства», а не «сопряжение».
- Кавычки — «ёлочки», тире — длинное, между числом и единицей — неразрывный пробел.
- Название приложения в тексте — в кавычках: «Полка».
- Заголовки и кнопки — без точки в конце. Пояснения — полными предложениями.
- Об ошибке — что случилось и что сделать: «Код не подошёл. Осталось попыток: 3».
- На «вы», без восклицательных знаков.

## Как добавить новое

**Кнопку:** выбрать вид из таблицы «Кнопки» → проверить, что главная на экране одна → текст-глагол
→ значку без текста дать подпись.

**Поле:** `field` с подписью сверху → высота 46 → ошибка под полем цветом `--warn`.

**Настройку:** найти раздел под катом по теме → добавить строку или переключатель → если темы нет,
новый раздел `Cut` с названием в одно-два слова.

**Экран:** заголовок → блоки через 22 → проверить на ширине 360 (телефон) и 1200 (компьютер),
в светлой и тёмной теме и хотя бы в двух схемах → пройти экран клавишей Tab.

## Что ещё расходится с правилами

Стили перенесены в kit из «Полки» без изменений — вид точь-в-точь прежний. Поправить отдельно:

- в стилях kit затемнение под окном поверх и белый текст опасной кнопки заданы цветом, а не переменной;
